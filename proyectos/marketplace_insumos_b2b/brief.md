# Marketplace B2B de insumos

## Por qué existe
Conectar personas/negocios que venden insumos con quienes los necesitan (ej.
un vendedor de café al por mayor con una cafetería que lo busca, que a su vez
necesita proveedor de panadería). Hoy ese match se hace de forma manual e
informal. En Colombia/LatAm no existe un marketplace de matching oferta-demanda
para pequeños proveedores — solo hay software de punto de venta (Loggro,
Vendty, Dixeb), no de conexión. Posible hueco real de mercado.

## Qué tiene que pasar para que esté listo
- [ ] Definir si arranca nicho (ej. alimentos/food service) o multi-categoría
- [ ] Definir modelo de monetización (comisión por transacción, suscripción,
      o leads)
- [ ] Validar la capa de delivery con repartidores independientes (moto/bici)
      como tercer lado del marketplace
- [ ] Validar demanda real con al menos un grupo piloto de proveedores y
      compradores en una zona/ciudad

## Próximos pasos
- [ ] Entrevistar 5-10 pequeños proveedores y 5-10 negocios compradores
      potenciales para validar el dolor real
- [ ] Definir el modelo de matching (qué datos sube cada lado: qué ofrece/
      necesita, ubicación, zona de reparto)
- [ ] Diseñar cómo se paga y asigna a los repartidores independientes

## Notas
Modelo de 3 lados: proveedor de insumo / negocio que necesita / repartidor
independiente — similar al patrón que usan Rappi o Uber para resolver
logística sin flota propia. Pendiente definir: cómo se les paga a los
repartidores (por entrega, por zona, tarifa dinámica), cómo se asignan
pedidos, y si el repartidor ve solo el pedido o también puede negociar
directo con quien compra/vende.
